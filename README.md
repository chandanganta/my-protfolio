# Chandan Ganta — Personal Portfolio

A responsive personal portfolio website introducing my background, technical interests, skills, projects, current learning goals, and ways to connect.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: DM Sans and Manrope

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Mobile navigation menu
- Smooth in-page navigation
- Scroll-reveal animations using the Intersection Observer API
- Automatically updated footer year
- Sections for About, Skills, Projects, Learning, Interests, and Contact

## Project Structure

```
my-protfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Keep `index.html`, `style.css`, and `script.js` in the same folder.

## Image Note

The hero image currently uses an external image URL. An internet connection is required to load it. You can replace the image URL in the `<img>` element in `index.html` with a local image path if you add your own image to the repository.
